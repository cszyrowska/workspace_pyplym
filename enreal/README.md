# EnReal vision documents

**Started 16 October 2026.** A set of separate vision documents describing one holistic vision, each focused on one part and one audience. When the set is complete, Cecy turns each into an HTML or Slidev presentation, in the style of the existing ProDanX decks for JJM and Sobey.

**Operating information:** [identity and accounts](../../operations/enreal-identity.md) is the starting point for the agreed domain and account status. The linked [money-routes guide for Kamila](../../operations/enreal-softocean-money-routes.md) explains EnReal's relationship to SoftOcean and the funding/payment alternatives; it is a draft, not a new offer or entity decision.

**Every document ends with a slide-by-slide outline for Cecy:** slide title, the one message, supporting points, and a visual suggestion. The narrative above the outline is the source; the outline is the deck.

## Rules for every document

1. **Say what exists and what is planned, separately.** Nothing that has not happened is written in the present tense. (Both independent reviews caught this.)
2. **Name partners only with their permission.** Until then: "a local partner", "a venue partner".
3. **Cite every number** and label secondary sources.
4. **One message per slide.**
5. **Consistent names:** SoftOcean, EnReal, PyPlym AI Edition, AI-Bench, AI Workbench, ProDanX (see [00 §3](00-vision-foundation.md)).
